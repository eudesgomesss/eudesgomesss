
## About Me

Sou Desenvolvedor Full Stack com foco em Python (Django, Django REST Framework e FastAPI) no back-end e React no front-end. Atuo no desenvolvimento de aplicações web modernas, APIs REST e integrações com serviços externos, utilizando JavaScript, TypeScript, PostgreSQL, MySQL e MongoDB. Trabalho com ambientes containerizados em Docker, versionamento com Git e integração de soluções de IA via OpenAI API, sempre seguindo boas práticas de desenvolvimento e metodologias ágeis como Scrum e Kanban.
